## Como estudar

1. Leia os objetivos e confira os pré-requisitos da trilha.
2. Execute a prática em um ambiente de estudo.
3. Tente os desafios antes de abrir a resolução comentada.
4. Registre o que fez, o resultado esperado e as dificuldades.
5. Explique sua solução: compreender o motivo de cada passo faz parte da atividade.

## Para professores

O [guia docente](GUIA-DOCENTE.md) reúne planejamento, rubrica de avaliação de 10 pontos e sugestões de adaptação. As durações são propostas e podem ser ajustadas à turma.

Os materiais são uma base inicial para uso e revisão pedagógica; não representam resultados de aplicação em sala já mensurados.

## Como contribuir

Encontrou um erro ou tem uma sugestão? Abra uma issue com a trilha, o trecho e a correção proposta. Para colaborar com código ou texto, use uma branch e descreva a alteração no pull request. Preserve os créditos de materiais de terceiros.

Não publique dados de alunos, senhas, tokens ou arquivos pessoais nas atividades. Use exemplos fictícios.
